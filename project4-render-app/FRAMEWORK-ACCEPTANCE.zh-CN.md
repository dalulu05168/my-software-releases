# P004 三层交易平台：功能框架、权限及验收清单

更新：2026-10-11。开发分支：`p004-account-flow-readonly-20261011`（源于 `p004-light-ui-render-20261011`）。本分支不部署、不合并 main，不触碰生产账户或资金。

## 1. 唯一账户结构

- `master` 总账户：后台登录（账号/密码/TOTP），能列出全部运营子账户，选择某个子账户查看它的客户；可不加筛选查询全部客户。
- `ops` 子账户：后台登录（账号/密码/TOTP），直接进入属于自己的客户列表；服务端必须强制限定身份绑定的 `ops_account_id`。
- `client` 客户：独立客户端登录，持仓与订单仅限本人身份，只读。不得通过后台页面或模拟镜像取得其他客户数据。

## 2. 本轮实现（只读查询，不进行交易）

1. 总账户 `子账户 → 查看所属客户 → 客户详情 → 订单 / 持仓 / 资金申请`；
2. 子账户 `会员管理 → 所属客户 → 客户详情 → 订单 / 持仓 / 资金申请`；
3. 客户列表和每客户详情使用后台只读 API，而非硬编码的 `initialCustomers` / `stocks`；
4. 报表后端新增两个可选过滤参数：`ops_account_id`、`user_id`。总账户可按子账户筛选；子账户无论传什么查询参数，都由服务器强制使用自己绑定的 ID，若传了不属于自己的 `ops_account_id`，返回 403；订单、资金、持仓分别按客户 ID 严格筛选；
5. 若数据库查询失败，则返回错误，不提供虚构的订单/余额；
6. 客户列表 CSV 仅导出当前已加载行（最多 200 条），不假称全量下载。

## 3. 数据流向

```text
master / ops 登录
  -> 服务器验证对应后台 session + role
  -> master 获取运营账户列表或 ops 进入所属客户
  -> GET project4-reporting-api?action=clients[&ops_account_id=...]
  -> 点击客户，取实际 user_id
  -> GET project4-reporting-api?action=orders|positions|cash&user_id=...[&ops_account_id=...]
  -> 服务器进行 user_id + ops_account_id 的联合权限过滤
  -> 页面只显示数据库返回的行
```

此外，client 使用 `project4-client-api` 的 login / portfolio / logout 等接口，与后台令牌互不通用。

## 4. 重要边界（不能称为已完成）

- **客户自助注册**：客户端发起 `?action=register`，但本分支客户 Edge Function 目前尚无对应实现。实际注册闭环不通过，不得宣传可注册。需实现经审计的邀请码核销、密码哈希写入、限流和原子创建操作，并部署相关数据库对象后再开放。
- **APP 镜像**：旧 `AppMirror` 组件含预设股票与客户数据，当前没有挂接在最新版真实客户列表上。不可当作真实客户手机；后续仅能对接同一权限范围内的实际客户 API 生成只读业务视图。
- **余额/入金/提现/下单**：真实资金账本、交易执行及审批接口未完成；保持关闭。
- **产品、风控、审计、通知、客服**：多数为未接入占位入口；不能将旧组件演示交互当做可用功能。
- **证券外部查询**：原证券管理 UI 还存在本地伪候选结果逻辑；必须改为真实 provider 查询并核对代码、市场、交易所后才能上线。
- **持久化与生产验证**：本次仅 GitHub 前端构建与静态回归通过，未核查生产 Supabase 部署、数据库迁移、真实数据以及浏览器中的登录与操作。CI 不是端到端数据库验收。

## 5. 必须执行的真实验收

- [ ] 总账户真实账号登录；成功列出实际子账户，并查看 A / B 子账户不同客户。
- [ ] OPS-A 登录并查看自己所属客户；直接请求 OPS-B 的 `ops_account_id` 必须返回 403。
- [ ] OPS-A 直接请求 OPS-B 某客户 `user_id` 的订单、持仓、资金申请，不得返回 B 客户任何数据。
- [ ] 真实客户列表/订单/持仓/资金申请数据与 Supabase 记录逐条一致。
- [ ] 客户详情为空、请求失败、会话过期时分别正确显示，不出现随机模拟数。
- [ ] 真实 CSV 下载的客户归属与权限一致；超过 200 条显示明确限制。
- [ ] 客户本人登录后只看到本人资产/订单；无订单执行能力。
- [ ] 三端在 16:9 电脑和手机上操作不遮挡；后台账户退出后旧查询缓存被清除。
- [ ] 完成真实注册、实名认证与权限修改、资金申请审批、安全审计后，才允许对外声明对应功能可用。
